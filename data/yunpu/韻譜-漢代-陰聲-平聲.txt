# 東漢

# 東漢有所不同，上古魚部麻韻與魚虞模押韻的極少。
# 只有上古魚部魚虞模三韻的韻例，可視爲舊讀（A類），也可視新讀（O類）。
# 這裏多數處理爲新讀（新魚部，O類）。
# 西漢多數處理爲舊讀（舊魚部，A類）。
# 這樣處理，主要是爲了減少同一作者的新舊讀混雜現象，並使合韻時的轉音更合理，
# 實際的音值，大可以是上古魚部魚虞模先演變爲ɔ，再演變爲o。

# 另外，上古侯部的侯尤，東漢主要還是 O類，只有少量兼押幽部。
# 上古幽部虞韻的少數幾個字（如“孚”），還是歸幽部，暫時未發現有押入 O類。

# 根據韻離合指數，模韻與“魚虞侯O”等可以分立。
# <模:魚> 韻離合指數: 53 (待定), 卡方值: 27.74 (分立), 模自押: 35.00, 魚自押: 48.00, 模魚合韻: 27.00, 模字次: 123.00, 魚字次: 224.00
# <模:虞> 韻離合指數: 39 (分開), 卡方值: 3.85 (--), 模自押: 35.00, 虞自押: 3.00, 模虞合韻: 9.00, 模字次: 123.00, 虞字次: 93.00
# <虞:魚> 韻離合指數: 101 (合并), 卡方值: 1.69 (相混), 虞自押: 3.00, 魚自押: 48.00, 虞魚合韻: 37.00, 虞字次: 93.00, 魚字次: 224.00
